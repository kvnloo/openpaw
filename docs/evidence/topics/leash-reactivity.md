# Leash reactivity and recovery

## What is supported
Pulling on walks varies with the dog, handler and equipment, so mechanical tension is not an interchangeable measure of behavioral reactivity. [Shih 2020](../cards/shih2020-do-canine-behavioural-assessments-and-characteristics-predict-the.md) [Shih 2021](../cards/shih2021-two-ends-of-the-leash-relations-between-personality.md) [Johnson 2024](../cards/johnson2024-comparing-efficacy-in-reducing-pulling-and-welfare-impacts.md)

OpenPaw should keep trigger, distance estimate and units, leash setup, handler action and the observable response separate; a pulled leash is evidence of tension, not evidence of fear. [Shih 2020](../cards/shih2020-do-canine-behavioural-assessments-and-characteristics-predict-the.md) [Shnookal 2025](../cards/shnookal2025-exploring-trainer-insights-and-understanding-of-on-lead.md) [Johnson 2024](../cards/johnson2024-comparing-efficacy-in-reducing-pulling-and-welfare-impacts.md)

## What is contested
Trainers described both fear and frustration as possible motivations and used different exposure criteria; those interviews did not test which explanation or protocol fit a given dog. [Shnookal 2025](../cards/shnookal2025-exploring-trainer-insights-and-understanding-of-on-lead.md)

## What is unknown
This sweep did not find a validated universal reaction distance, a scoring rule for “trigger stacking,” or a verified field recovery window; log encounter timestamps and a separately defined return to observable baseline, with “not observed” when follow-up ends first. [Shnookal 2025](../cards/shnookal2025-exploring-trainer-insights-and-understanding-of-on-lead.md) [Beerda 1998](../cards/beerda1998-behavioural-saliva-cortisol-and-heart-rate-responses-to.md) [Shih 2020](../cards/shih2020-do-canine-behavioural-assessments-and-characteristics-predict-the.md)
